# AI智能助手功能说明

## 📋 功能概述

本项目已集成AI智能助手功能，提供智能对话、问题解答、系统诊断等服务。

## 🚀 快速开始

### 1. 访问方式

- **浮动按钮**: 页面右下角的AI助手浮动按钮
- **独立页面**: 访问 `/ai-chat` 路由
- **菜单导航**: 在侧边栏中找到"AI智能助手"

### 2. 功能特性

- 💬 **智能对话**: 与AI进行自然语言交互
- 🔧 **系统诊断**: 获取系统问题诊断建议
- 📚 **知识问答**: 回答运维相关问题
- ⚙️ **个性化设置**: 自定义AI模型和对话风格
- 📱 **响应式设计**: 支持桌面和移动端

## 🛠️ 技术架构

### 前端组件结构
```
src/
├── components/AiChat/          # AI聊天组件
│   ├── index.vue              # 主聊天组件
│   └── FloatingButton.vue     # 浮动按钮组件
├── views/aiChat/              # AI聊天页面
│   └── index.vue              # 聊天页面
├── api/ai.js                  # AI接口对接
└── utils/aiMock.js            # AI服务模拟器
```

### 接口设计
- `POST /ai/chat` - 发送消息
- `GET /ai/models` - 获取模型列表
- `GET /ai/status` - 检查服务状态
- `GET /ai/config` - 获取配置
- `PUT /ai/config` - 更新配置

## 🔧 配置说明

### 环境变量
```bash
# 启用AI模拟模式（开发环境）
VUE_APP_AI_MOCK=true

# AI服务地址（生产环境）
VUE_APP_AI_BASE_URL=https://your-ai-service.com
```

### 模拟模式
开发环境默认启用模拟模式，无需真实AI服务即可测试功能。

## 🔌 后端对接

### 接口规范
```javascript
// 发送消息接口
{
  "message": "用户输入的消息",
  "history": [
    {
      "type": "user|ai",
      "content": "消息内容",
      "timestamp": 1234567890
    }
  ],
  "sessionId": "session_123456",
  "timestamp": 1234567890
}

// 响应格式
{
  "success": true,
  "data": {
    "content": "AI回复内容",
    "timestamp": 1234567890,
    "sessionId": "session_123456",
    "messageId": "msg_123456"
  }
}
```

### 部署步骤
1. 部署AI后端服务
2. 配置API地址
3. 关闭模拟模式
4. 测试接口连通性

## 🎨 自定义配置

### 修改样式

### 添加功能
在 `src/api/ai.js` 中添加新的接口方法。

### 扩展组件
基于现有组件创建新的AI功能组件。
