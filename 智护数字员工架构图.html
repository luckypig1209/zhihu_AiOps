🔄 Skills 工作流程
1

Skills 加载

AI Connector 启动时扫描 /app/skills/*.md，将所有 .md 文件加载到内存。通过 Docker Volume 从宿主机 references/ 目录挂载。

2

注入 System Prompt

buildSkillsDocs() 将所有 skill 内容拼接到 System Prompt 的「Skills 参考文档」章节，每个截取前 2000 字符。模型在回答时可以参考这些文档。

3

LLM 意图识别 + Tool 选择

模型根据用户查询 + Skills 文档上下文，决定调用哪个 Tool（Function Calling）。例如看到 api_victoriametrics.md 中的指标名，就会用 cpu_usage_idle 而非 node_cpu_seconds_total。

4

Tool 执行

AI Connector 根据模型返回的 tool_calls，在 executeToolCall() 中分发到对应的 JS 函数执行。当前支持 5 个 Tool：query_victoriametrics · query_zabbix · query_zhihu_api · add_os_monitor · batch_add_os_monitor

5

结果回传 + 流式输出

Tool 执行结果返回给 LLM，模型基于数据生成最终回复，通过 WebSocket 流式推送到前端展示。
